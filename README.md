# ⚽ Jovem Fla — Paixão e Vibração

Landing page institucional dedicada à **Jovem Fla**, apresentando a história, a identidade e os principais cantos da torcida organizada do Clube de Regatas do Flamengo.

---

## 📋 Sobre o Projeto

Este projeto consiste em uma página web temática desenvolvida para celebrar a energia e o apoio da torcida rubro-negra. A página possui seções informativas e chamadas para ação (*Call to Action*) voltadas para novos integrantes.

### ✨ Seções da Página

- **Banner Principal (Hero):** Chamada de impacto com convite para participação na torcida.
- **Nossa História:** Resumo sobre a dedicação, presença nos jogos e paixão pelo Flamengo.
- **Principais Cantos:** Lista detalhada com os gritos e cantos tradicionais da arquibancada:
  1. *Nosso Lema é Vibração*
  2. *Deixa Passar a Jovem Fla*
  3. *Êêoo, Sou da Jovem Fla*
  4. *Voa, Voa, Urubu*
- **Chamada para Ação (CTA):** Convite final para vestir as cores e fazer parte da história rubro-negra.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web padrão:

- **HTML5** — Estruturação semântica do conteúdo.
- **CSS3** — Estilização com identidade visual rubro-negra (preto e vermelho).
